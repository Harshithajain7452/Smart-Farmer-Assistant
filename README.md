# Smart Farmer Assistant

An AI-powered agricultural support platform that helps farmers make informed decisions using machine learning, weather forecasting, market insights, soil information, government schemes, and intelligent farming assistance.

## Features
- Crop Disease Detection (CNN)
- Weather Forecasting
- Market Price Analysis
- Nearby Market Finder
- Government Schemes
- Soil Information System
- AI Chatbot
- Farmer Calendar
- Crop Recommendation
- Yield Prediction
- Multilingual Support

## Tech Stack
- Python
- Flask
- MySQL
- TensorFlow
- Scikit-Learn
- HTML/CSS/JavaScript
- REST APIs
